# 해남이의 당직에서 살아남기

배에서 벌어지는 비상상황에 알맞은 해기사 직급 카드를 배치해 열 번의 당직을 버티는 1인용 턴제 카드 디펜스 게임입니다.

[게임 바로 플레이하기](https://haenam-duty-survival.kfkal1809.chatgpt.site)

## 게임 규칙

- 선박 내구도 12, 매 턴 당직 포인트 6으로 시작합니다.
- 갑판원·기관원, 1~3항사·기사, 선장·기관장과 조리장까지 11종의 직급 카드가 등장합니다.
- 손패에서 카드 1~3장을 선택해 사건의 갑판·기관·항해 요구치를 채웁니다.
- 성공하면 100점, 요구치와 정확히 일치하면 50점, 조합이 발동하면 30점을 추가로 얻습니다.
- 실패하면 선박 내구도가 2 감소합니다.
- 사건에 맞는 대응 조합이 손패에 포함되며, 사용한 카드는 다음 당직 한 번을 쉬고 다시 덱으로 돌아옵니다.
- 기관 사건에는 기관장, 갑판·항해 사건에는 선장이 70% 확률로 등장합니다(직전 당직에서 사용했다면 한 번 휴식).
- 조리장은 1 당직 포인트를 쓰는 지원 카드이며, 함께 선택한 카드와 협동 보너스의 이번 사건 대응력을 1.5배로 올립니다(소수점 올림).
- 열 번의 당직을 버티면 승리하고, 내구도가 0이 되면 게임오버입니다.
- 시작 전에 닉네임을 입력하면 게임 종료 후 기기별 최고 기록이 전체 랭킹에 저장됩니다.
- 전체 랭킹은 상위 50명과 성공 횟수·칭호를 함께 보여줍니다.

## 성공 횟수 칭호

- 0~1회: 멀미하는 실습생
- 2~3회: 구명조끼 꽉 맨 갑판 병아리
- 4~5회: 커피로 버티는 당직 요정
- 6~7회: 파도와 밀당하는 바다 해결사
- 8~9회: 선장님도 찾는 만능 해남이
- 10회: 갈매기도 경례하는 전설의 해남이

각 칭호는 결과 화면에서 서로 다른 캐릭터 일러스트와 대사를 표시합니다.

## 실행

```bash
npm ci
npm run dev
```

검증 명령은 `npm run lint`, `npm run test:unit`, `npm run build`입니다.

## 기술 구성

- Next.js, TypeScript, Tailwind CSS
- 브라우저 `localStorage`에 최고 점수·최고 칭호·사운드·닉네임·기기 식별값 저장
- Cloudflare D1에 공개 닉네임과 기기별 최고 기록을 저장하는 전체 랭킹
- 로그인, 결제 없음
- 390px 모바일 화면 우선 반응형 UI

## 일러스트

사용자가 제공한 《당직 캐릭터》 시트에서 11개 직급을 외곽선대로 분리한 투명 PNG를 사용했습니다. 원본 시트는 수정하지 않았습니다.
